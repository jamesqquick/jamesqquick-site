## Overview

Build The Weekender, a local events guide for a single Memphis weekend. The project uses Astro for content, routing, and static pages, then adds React only where the interface needs browser state.

## What you will build

You will build an events directory with event, venue, and category pages. Visitors can filter events, save choices in their browser, and review a weekend plan grouped by day. The finished site also includes metadata, RSS, a sitemap, a custom 404 page, and a test suite.

## What you will learn

- Set up an Astro 7 project and organize pages, layouts, components, and styles.
- Model events and venues with typed content collections and references.
- Generate static routes from content while keeping relationships type-safe.
- Add React islands for filtering and a saved plan without turning the site into a client-rendered app.
- Synchronize saved event state across independent islands with `localStorage` and browser events.
- Test data utilities, React components, user flows, responsive layouts, and accessibility.

## Who it is for

This course is for web developers who know HTML, CSS, and JavaScript, have used basic React, and want to learn how Astro fits into a production project.

## Prerequisites

You should be comfortable creating a small website, using the command line, and reading TypeScript. Prior Astro experience is not required.

## How to use the course

Work through the sections in order and build each part in the reference project. Run the relevant checks as you go, then finish with the full validation command before treating the site as ready to ship.
